# Hatyai Autogate — แนวทางเว็บใหม่

เว็บต้นทาง: https://www.hatyaiautogate.com/

## วิเคราะห์เว็บเดิม

- ข้อมูลบริการมีครบ ทั้งประตูรีโมทบานเลื่อน บานสวิง แขนกั้นทาง ประตูอัตโนมัติ และคีย์การ์ด แต่กระจายอยู่หลายหน้ากับเมนูย่อยจำนวนมาก
- หน้าแรกให้พื้นที่หลักกับโปรโมชันและภาพสินค้า ทำให้ผู้เข้าชมต้องมองหาข้อมูลบริการและช่องทางติดต่อ
- พื้นหลังและองค์ประกอบตกแต่งหลายสีลดความชัดของเนื้อหา โดยเฉพาะบนหน้าจอเล็ก

## แนวทางใหม่

- หน้าเดียวแบบ minimal: บริการหลัก → ภาพรวมร้าน → Facebook และ LINE → ช่องทางติดต่อ
- ใช้สีน้ำเงินเข้มกับสีแดงจากอัตลักษณ์เดิม แต่ลดองค์ประกอบตกแต่ง
- เน้นข้อความสั้นที่บอกประเภทงานและปุ่มโทร/LINE ให้เข้าถึงได้ทันที
- ไม่ลงราคา รุ่นสินค้า โปรโมชั่น หรือระยะรับประกัน เพราะข้อมูลเหล่านี้อาจเปลี่ยนและควรยืนยันกับร้านก่อนเผยแพร่
- ภาพประตูบนหน้าแรกเป็นภาพประกอบที่สร้างขึ้นใหม่ ไม่ใช่ภาพผลงานติดตั้งจริงของร้าน
- โลโก้ร้านต้นฉบับเก็บไว้ที่ `assets/LOGO_HATYAI-autogate.png` และใช้ในส่วนหัวกับ favicon
- Facebook Page แสดงผ่าน Facebook Page Plugin พร้อมลิงก์เปิดเพจโดยตรง และใช้ LINE Official Account `@hatyaiautogate` ตามข้อมูลที่ร้านแจ้ง

## ไฟล์

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง ไม่มีขั้นตอนติดตั้ง และสามารถนำไฟล์ทั้งหมดขึ้นโฮสต์แบบ static ได้

ข้อมูลติดต่ออ้างอิงจากเว็บเดิม ณ วันที่ 22 กันยายน 2026 ควรตรวจสอบเบอร์ ที่อยู่ อีเมล และ LINE ก่อนนำไปใช้จริง
